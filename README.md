# Bluetooth + Raspberry Pi ROS 2 + браузер

Комплект для существующего четырёхколёсного Arduino-робота: исходные команды Bluetooth сохранены, добавлены USB-связь с Raspberry Pi, ROS 2 Jazzy, Wi-Fi-пульт для браузера Android/Windows и изображение USB-камеры.

**Перед подключением: перенесите провод ENA с D1 на D9.** D0/D1 нужны аппаратному Serial через USB. Профиль рассчитан на Uno R3 / классический Nano с ATmega328P, а не Uno R4/ESP32.

Начните с [инструкции установки](docs/INSTALL_RU.md) и [таблицы проводов](docs/HARDWARE_RU.md). [Архитектура и протокол](docs/ARCHITECTURE_RU.md) объясняют переключение пультов; [проверки](docs/TESTING_RU.md) отделяют программные тесты от испытаний на роботе.

- `arduino/blu_drive/`: три новых файла прошивки; открыть `blu_drive.ino` в Arduino IDE.
- `original_bluetooth/`: точные копии трёх исходных файлов пользователя.
- `ros2_ws/src/robot_web_teleop/`: пакет ROS 2, Python-узлы, HTML/JavaScript, launch и настройки.
- `scripts/run_robot.sh`: полный запуск; по умолчанию управление в прямой видимости.
- `scripts/view_camera.sh`: просмотр камеры без управления.
- `scripts/install_jazzy.sh`: установка зависимостей на свежей Ubuntu 24.04.

Телефон открывает **http://192.168.0.28:8080/**. SSH с Windows: `ssh shapturov@192.168.0.28`. Адрес должен принадлежать вашей Pi; закрепите его в DHCP роутера.

Bluetooth получает приоритет. Нулевые команды Wi-Fi не перебивают Bluetooth. Кнопка СТОП в браузере запрашивает остановку обоих источников. После возврата из Bluetooth или ошибки канала браузер требует нового нажатия «Взять управление».

Bluetooth по умолчанию совместим с приложениями, отправляющими команду один раз при нажатии и S/D при отпускании: таймаут Bluetooth отключён. В этом режиме потеря Bluetooth-связи сама по себе не обнаруживается. Варианты с повтором команд/выводом STATE описаны в HARDWARE_RU.md.

Это ручное управление без SLAM, автопилота и модели мира. Энкодеров и подтверждения фактической скорости колёс в исходных файлах нет. RTX 4090 и ROS на Windows для браузерного управления не требуются.
