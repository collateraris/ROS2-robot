# Код телефона

index.html — полный пульт для браузера Android/Windows: вход с паролем, камера, джойстик, режим прямого обзора или проверки видео, СТОП Wi-Fi и Bluetooth. camera_view.html — отдельный экран просмотра без движения.

Открывайте на телефоне http://192.168.0.28:8080/ после запуска ROS-пакета на Pi. Устанавливать ROS или APK на Android не нужно. Открытый через file:// локальный HTML не является работающим пультом: ему нужны HTTP API и WebSocket web_node на Pi.

В полном проекте эти файлы лежат в ros2_ws/src/robot_web_teleop/web/. При их изменении повторите colcon build --symlink-install и перезапустите launch. Отдельный phone-архив содержит только клиент; сервер и motor_bridge находятся в полном/ROS2 архивах.

При переключении на Bluetooth приложение пульта или другой телефон продолжает общаться с прежним Bluetooth-модулем Arduino. Pi не переустанавливает Bluetooth-соединение и не эмулирует этот модуль.
