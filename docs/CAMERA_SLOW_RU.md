# Текущая USB-камера

Из измерений пользователя: `/dev/video0`, OpenCV 4.6.0, UVC MJPG 640×480, драйвер сообщает 30 fps. Кадры читаются успешно: первое чтение около 2.88 с, последующие около 0.57–0.75 с. Это примерно 1.3–1.8 кадра/с, а не фактические 30 fps. Причина медленной работы по этому выводу не установлена.

Новый пакет не закрывает исправно выдающую кадры камеру только потому, что `read()` занял более 0.5 с. Такие кадры попадают в предпросмотр. Ошибка/пустой кадр вызывает переподключение. При зависшем драйвере поток ROS продолжает работу, но OpenCV/V4L2 не обеспечивает переносимый жёсткий таймаут read(); может понадобиться перезапуск камеры/процесса.

Для просмотра без управления:

```bash
cd ~/robot_bluetooth_ros2
bash scripts/view_camera.sh camera_device:=/dev/video0
```

Для управления с наблюдением за самим роботом:

```bash
bash scripts/run_robot.sh serial_port:=/dev/ttyACM0 camera_device:=/dev/video0 camera_required:=false
```

На телефоне: `http://192.168.0.28:8080/`. Реальный serial_port может быть `/dev/ttyUSB0` или `/dev/serial/by-id/...`.

Режим `camera_required:=true` включает более строгую проверку видео перед движением. При нынешней частоте он может блокировать пульт. Предпросмотр не превращается в пригодное для удалённого вождения видео от увеличения разрешённого возраста.

Остановите предыдущие процессы перед диагностикой. Одна камера должна захватываться одним процессом:

```bash
v4l2-ctl -d /dev/video0 --list-formats-ext
v4l2-ctl -d /dev/video0 --list-ctrls-menus
```

В присланном списке есть MJPG 640×480@30 и YUYV 640×480@30. Для сравнения используйте отдельный просмотр, остановив старый:

```bash
bash scripts/view_camera.sh camera_device:=/dev/video0 pixel_format:=YUYV
```

Сравнивайте частоту поступающих новых кадров; возвращаемое True из `set()` и число в `CAP_PROP_FPS` сами по себе её не доказывают. Проверьте освещение, доступные настройки экспозиции, USB-порт/кабель/питание, но не меняйте несуществующие в списке контролы и не считайте какой-либо из этих факторов установленной причиной.

Документация: [OpenCV VideoCapture 4.6](https://docs.opencv.org/4.6.0/d8/dfe/classcv_1_1VideoCapture.html), [V4L2 frame interval](https://docs.kernel.org/userspace-api/media/v4l/vidioc-g-parm.html), [контролы камеры V4L2](https://docs.kernel.org/userspace-api/media/v4l/ext-ctrls-camera.html).
