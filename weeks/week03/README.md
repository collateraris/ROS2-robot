# Неделя 3: локальный LLM/VLM и исполнение через Nav2

Полная инструкция: [docs/WEEK03_RU.md](../../docs/WEEK03_RU.md).

`rules` — проверяемый baseline с тем же исполнительным кодом. `ollama` —
реальный HTTP-инференс локальной `qwen2.5vl:7b`. Обе ветки выдают только
символические действия над известными ID и именами, не моторные команды.

Первый запуск всегда shadow:

```bash
source scripts/env_robot.sh
ros2 launch room_tasks tasks.launch.py backend:=rules \
  use_sim_time:=true robot_radius_m:=0.19 standoff_m:=1.0
```

Это параметры симуляции недели 1. Для реального робота задайте
`use_sim_time:=false`, измеренный радиус и выбранную дистанцию подхода.

Навигационную основу запускать с `start_mission:=false`, чтобы старый
`room_mission` не конкурировал за Nav2. Это не запускает двигатель и не
заменяет отдельно проверенные SLAM/восприятие недели 1–2.
